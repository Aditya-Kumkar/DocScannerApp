# 🧈 pdfbutter

> **Smooth as butter.** A minimal, serene, and functional Android document scanner and PDF toolkit.

Built with **Kotlin**, **Jetpack Compose**, and the **Google Play Services ML Kit Document Scanner API**.

---

## ✨ Features

- **🧈 Butter-Smooth Scanning**: On-device real-time border detection, perspective flattening, and magnifying loupe adjustments.
- **📄 Native In-App PDF Reader**: Open and read documents with smooth continuous vertical scrolling right inside the app.
- **✨ Spacious & Serene Tiles**: Clean, breathable document cards showing only Title, Date, Time, and File Size.
- **🎯 Multi-Select Mode**: Long-press any document to enter selection mode and perform bulk actions.
- **🔗 Merge PDFs**: Select 2 or more PDFs and combine them into a single ordered document.
- **✂️ Split PDF**: Extract custom page ranges into brand-new standalone PDFs.
- **🗜️ Compress PDF**: Shrink PDF file size with preset quality targets (High Compression, Balanced, Light).
- **🌓 Dark Mode**: Toggle seamlessly between Light, Dark, and System default modes with one tap.
- **✏️ Rename & Organize**: Effortlessly rename documents with instant feedback.
- **📤 Share & Export**: Open in any PDF viewer or share via WhatsApp, Gmail, Drive, etc.
