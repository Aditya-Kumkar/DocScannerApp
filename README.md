# 🧈 pdfbutter

> **Smooth as butter.** A minimal, playful, and functional Android document scanner.

Built with **Kotlin**, **Jetpack Compose**, and the **Google Play Services ML Kit Document Scanner API**.

---

## ✨ Features

- **🧈 Butter-Smooth Scanning**: On-device real-time border detection and deskewing.
- **Draggable Precision Adjustments**: 8-point corner & edge draggable pins with magnifying loupe for micro adjustments.
- **🌓 Dark Mode**: Toggle seamlessly between Light, Dark, and System default modes with one tap.
- **✏️ Rename & Organize**: Effortlessly rename scanned PDFs with a single tap.
- **📄 Multi-page Support**: Scan receipts, notes, and multi-page books into single, crisp PDFs.
- **📤 Share & Export**: Open in any PDF viewer or share via WhatsApp, Gmail, Drive, etc.
